Connect to this server

  1. Close FUSER.
  2. Open %LOCALAPPDATA%\Fuser\Saved\Config\WindowsNoEditor\Game.ini in a text editor (create it if it doesn't exist).
  3. Add the lines below, then save. Keep EnvironmentSettings= on a single line: the game crashes if it is split.
{{.Ini}}
  1. Make Game.ini read-only, so the game can't overwrite your changes:
    • In File Explorer, right-click Game.ini and choose Properties. On the General tab, tick Read-only, then click OK.
    • Or run this in PowerShell:
Set-ItemProperty "$env:LOCALAPPDATA\Fuser\Saved\Config\WindowsNoEditor\Game.ini" -Name IsReadOnly -Value $true

To edit Game.ini later, untick Read-only first (or run the same command with $false).

  1. Start FUSER.

Optional: add the mod pack

You're ready to play. The free mod pack adds key and BPM display, bigger crates, song search and custom songs that download automatically in multiplayer.

{{if .SeparateStock}}

Without the mod pack you can still use profiles, following, invites and public lobbies, but you're matched only with other players who don't have it, and you can join the Diamond Stage only during events that allow the stock game.

{{else}}

Without the mod pack you can still play online, including with mod pack players.

{{end}}

Custom songs aren't shared between players without the mod pack. A custom song only plays correctly when everyone in the session has the same song installed; otherwise the mix is unreliable and can throw off gameplay timing.

In the game

  • Key and BPMEvery song item shows its key and tempo, swapping places with Genre and Year. Settings › General › Key and BPM Display
  • Key labelsShow keys as flats (D♭), sharps (C♯) or both (C♯/D♭). Settings › General › Key Labels
  • Bigger cratesPlay crates of up to 144 songs and 120 snapshots in freestyle (144 slots in total, up from 24 songs). Every 8 songs get their own tab, up to 18 song tabs.
  • Crate editorSearch the song library, and get a tab for every song and snapshot page of a large crate. Settings › General › Song Search Bar
  • New crate sizesSet the song and snapshot slots of new crates, up to 144 songs, without editing Game.ini. Settings › General › New Crate Song Slots

Everything the original song loader does

  • Custom songsPut custom song .pak and .sig files in Fuser\Content\Paks\custom_songs and they're in the game, free to play.
  • Event-reward songsSongs from FUSER's past in-game events are unlocked for free.
  • Wider BPM rangeTempos from 60 to 200 BPM, up from the stock 90 to 157.
  • No more unlock pakAdd or remove custom songs without deleting customSongsUnlocked_P.pak: songs are unlocked when the game starts. An old copy is renamed out of the way for you.
